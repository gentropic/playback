# The Book That Plays Back

*an unbeatable game of tic-tac-toe — and other games*

A book you play **against**. You make a move, turn to the page the board
sends you to, and find the book has already replied — its move ringed. Every
answer was worked out in advance by minimax (with a trap-maximising
tie-break), so the book never thinks and never hesitates: it simply knows.
The whole thing is generated by a short Python program and rebuilds,
identically, from a single random seed.

Five games live inside:

- **Tic-tac-toe** — cannot lose; the most you can take is a draw.
- **Hexapawn** — cannot lose.
- **Notakto** — the misère one (three in a row *loses*); cannot lose.
- **Nim** — *you can beat this one.* There is exactly one perfect line.
- **Twenty-one** — a misère subtraction game; cannot lose.

Along the foot of every page runs a second thread — a history of machines
that play, from Babbage's 1834 daydream to AlphaZero — which you can read
straight through, cover to cover. The back matter includes an essay on
building a matchbox learning machine (Gardner/Michie's MENACE, in beads), an
essay on the Sprague–Grundy theorem ("every game is Nim in disguise"), a
small glossary of combinatorial game theory, a cut-out matchbox kit, and a
certificate for anyone who manages a draw — or beats the Nim.

## Editions

The generator emits two editions, each in colour and black-and-white:

| Edition | Layout | Pages |
|---|---|---|
| **wide** | one board per page | 547 |
| **compact** | tic-tac-toe & notakto grids two-up (page + U / L), everything else one-up | 310 |

The black-and-white files are the print masters; the colour files render the
book's last move and the navigation numbers in signal red. The **compact**
edition is the one intended for printing.

## Build

Requirements: a TeX distribution with **XeLaTeX**, and the two fonts
(both OFL): **Barlow** and **Space Mono**. `forme.sty` expects them by path;
adjust the `Path=` entries if yours live elsewhere.

```sh
python3 book.py            # writes four .tex files
# compile each with TWO passes (the foot timeline uses remember-picture overlays):
xelatex the_book_compact_bw.tex && xelatex the_book_compact_bw.tex
```

`cover.py` builds the parametric hardcover wrap (`cover.pdf` and a proof).
The spine width depends on the bound page count and paper stock, so set it
once the edition and paper are fixed.

Everything is deterministic: the random seed is 43, and the colophon prints a
SHA-256 of `book.py` + `forme.sty` so any copy can be traced to its source.

## Files

- `book.py` — the generator: game engines, renderers, and per-edition assembly.
- `forme.sty` — *Forme*, the LaTeX style (A6 geometry, palette, fonts, the foot timeline and fore-edge index). A print companion to the Switchboard design system.
- `cover.py` — the hardcover cover/wrap generator.

## Print specifications

A6 (105 × 148 mm) hardcover. Interior on Sulfite 90 g, 1×1 black-and-white
(90 g for opacity — the solid marks would ghost through 75 g). Cover on matte
coated stock with matte lamination, 4×0.

## Credits & prior art

The learning-machine idea is Martin Gardner's hexapawn box (*Scientific
American*, 1962) and Donald Michie's MENACE (*The Computer Journal*, 1963).
Nim: C. L. Bouton (1901). Notakto: Thane Plambeck & Greg Whitehead (2013).
The general theory of who-wins, and the surreal numbers behind the partisan
games: Berlekamp, Conway & Guy, *Winning Ways* (1982), and Conway, *On
Numbers and Games*.

A book that plays you is not a new idea: *Tic Tac Tome* (Willy Yonkers,
Quirk Books, 2014) is a published predecessor in the same spirit. This one
was conceived independently and shares none of its text, code, or page
numbers.
